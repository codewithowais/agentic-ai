# Agentic AI — From Foundations to Advanced Systems

A 16-week, hands-on course on designing, building, evaluating, and shipping AI agents,
for learners who already know ML/LLM basics and want to reach advanced agent-building skill.

## The site

| Page | File | What it is |
|------|------|------------|
| **Syllabus** | [`index.html`](index.html) | Course description, outcomes, 16-week schedule, assessment, capstone, policies |
| **Topic Guide** | [`topics.html`](topics.html) | Every topic defined with a concrete example — searchable, cross-linked, with related-topic links |

The two pages link to each other: click any **topic chip** in the syllabus to jump to its
explanation in the guide, and use the **Topic guide / Syllabus** buttons in the header to switch.

- Keyword search on the guide (press <kbd>/</kbd>).
- Light/dark theme, responsive, scrollspy navigation.
- `SYLLABUS.md` holds the plain-Markdown source of the syllabus.

## Local preview

Just open `index.html` in a browser — no build step, no dependencies.

## Deployment

Served via **GitHub Pages** from the `main` branch root.
